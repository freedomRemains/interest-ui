### 各種コマンド(いずれもWindowsPowerShellからの実行を推奨)

- 初期構築(Gitからの資材取得後に実行、「node_modules」が形成され、依存関係が解決できるようになる)

```Next.js
npm install
```

- プログラムの起動

```Next.js
npm run dev
```

- 全テストの実行

```Next.js
npm test
```

- カバレッジ測定

```Next.js
npm run test:coverage
```
